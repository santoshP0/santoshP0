## 🧑‍💻 About Me

I'm a **mobile app developer** who enjoys going past the surface of cross-platform frameworks — building **native modules**, wiring up **background services**, and shipping features that feel truly platform-native. Currently focused on React Native apps backed by custom Kotlin / Objective-C bridges.

- 🔭 Currently building deep native integrations for React Native apps
- 🌱 Exploring CarPlay / Android Auto extensions
- 💡 I like tools that make other developers' lives easier
- ⚡ Fun fact: I'd rather write a native module than fight a workaround
